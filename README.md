# aitm — planning branch

This branch holds all story planning and tracking data for [kburson/aitm](https://github.com/kburson/aitm).
It is a sister of `trunk`, not a feature branch:

| Branch     | Holds                                                      | Merged into the other? |
| ---------- | ---------------------------------------------------------- | ---------------------- |
| `trunk`    | Deployable implementation code                             | Never                  |
| `planning` | Ideas, drafts, stories, designs, plans, reviews, events    | Never                  |

Both branches are protected: no deletion, no force-push, no history rewrite.
`planning` only ever moves forward, so every commit SHA and every file link on it stays valid permanently.

Start at [`.aitm/README.md`](.aitm/README.md) for the folder layout.
