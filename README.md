# aitm

Rewrite of ai-task-manager using python and typescript

## Backlog dependencies

Use `make backlog` to reconcile open GitHub relationship changes and read the current Blocked-By projection. Use the local dependency sync to edit relationships or reconcile a single issue or closed issues. See [Use the local Blocked-By sync](docs/blocked-by.md).

See [Repository CI](docs/ci.md) for the PR validation workflow.
