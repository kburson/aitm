Provide a manually dispatched diagnostic route guarded to the same default trunk. Treat dispatch and schedule as distinct event identities. Run once daily at 03:17 UTC. Require a scheduled run created at or after the latest daily slot, with a 45-minute grace period before a missing slot is incomplete. An old rerun cannot fill a new slot. Diagnose dispatch separately from the exact schedule event.

Add a read-only consumer that pins the repository, workflow ID/path, exact current default branch and SHA, latest run/attempt and Actions job. Replay successful full receipts only when attempt artifacts, exact profile inventory and all phases agree. Preserve a verified failure if its artifact is unavailable. Keep stale, delayed, incomplete and red distinct. Only real scheduled evidence may qualify the scheduled event route.

Test stale and mismatched SHA/attempt, missing artifacts and completion, exact full successful evidence, and a negative fixture. Run an actual full hosted shadow, retain provider and runtime logs, and obtain independent review.
