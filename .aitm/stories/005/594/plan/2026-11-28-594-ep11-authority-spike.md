## First experiment

The [throwaway probe](2026-11-28-594-authority-probe.py.txt) ran real Git object writes and compare-and-swap ref updates in a temporary bare repository. [Observed output](2026-11-28-594-authority-probe-output.txt). Source SHA-256 is `9f33910b2faf59870fb4f619b03f2ea858c3eecbbd5094ef720261601bc8affc`.

- Stop first defeated the stale grant CAS. A fresh read found a closed clock and no grant.
- Grant first defeated the stale stop CAS. A rebuilt stop retained the original grant. Issued, terminal absence and unknown fixture outcomes preserved the closed clock. A repeat from the old expected revision failed.
- Only the winning candidate's child and reciprocal facts became visible on the authority ref.
- Moving the ref left captured pinned Git bytes unchanged. Changing the source, lock, or inventory changed the environment fingerprint.

This establishes feasibility of the Git ordering. The probe models custody inputs and cache identity. It does not exercise the production issuer, subprocess launch, installed capture/provision adapters, or a durable provider absence proof. The existing #593 fault probes demonstrate the current installed Git gap with a deterministic issuer. The production prerequisite must qualify real Git authority and a provider double that exercises exact claim and lost-reply evidence. Keep the spike open for review of production scope, dependency recommendations, and proof ownership.

## Proposed proof ownership

1. #595 should require the same pinned origin and reservation in the transaction that grants every new C20 send, and recheck before provider dispatch. An authoritative stop that wins first leaves no new grant or send. Claim-first recovery observes the same claim without granting another send.
2. #595 should provide an explicit, clock-neutral C30 custody operation. Confirmed issuance preserves the exact identity for a scope decision. Terminal absence demands authoritative non-issuance or fenced-claim proof. Unknown custody stays pending. Ordinary graduation retains its established provider-independent contract.
3. #40 consumes the new operation without inventing custody, then #41 asserts the corresponding admission and result boundaries. #30 and #31 should show that exact preparation outputs remain stable as inputs and become stale when the authority coordinates change. Their production security and containment contracts keep their accepted owners.
