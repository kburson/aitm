## Contract and custody

`WatchRoot` carries an opaque keyed root identifier, an absolute transient physical directory path and expected device/inode. Roots must be admitted by the coordinator later. WatchSet validates the closed input, obtains the existing no-follow directory chain in `sources.scan._directory`, and shows root identity before and after enrollment and when emitting root outcomes. The scan helper provides physical traversal without imposing private ledger directory modes on an otherwise approved provider source. Duplicate approvals of the same physical root coalesce at the existing boundary where possible, and the JIT fixes the exact handling of a conflicting key or alias. WatchSet emits only bounded transient changes and reconcile, root-lost or root-replaced hints. Watch hints grant no stream or payload authority. It opens no transcript data.

On Darwin, one owning thread creates, schedules, starts, drives and retires the FSEvents stream. Keep CF objects and callback storage live for the entire thread. Initial readiness requires a successful stream start and physical recheck. A coalesced startup reconciliation request follows. Use bounded run-loop waits to make early stop reliable. A stop request wakes the thread. Successful join permits the caller to release its callback reference. The owning thread retains resources if a bounded join fails, and the close reports failure without unsafe release. Verify drop, coalesced subtree, event-wrap and root flags. On Linux, the watcher owns one checked nonblocking close-on-exec inotify fd and a bounded descriptor-to-root mapping. Use an already open directory for physical enrollment and check syscalls and mappings after each enrollment. New subdirectories request reconciliation to cover writes that occur before watch enrollment. Rebuild bounded registrations on overflow or stale root state. Retire them with the fd. Linux can use the per-process descriptor namespace when available for fd-bound enrollment. A capability failure uses bounded reconcile hints for only those admitted roots.

Use bounded queues and root/directory limits and coalesce pressure at root granularity. WatchSet offers finite `events(timeout)`, idempotent `close()`, and context management. Its fallback only schedules periodic reconciliation. #326 reads metadata and opens selected eligible sources. #121 owns scheduling, sanitized loss coverage and operator workflows. Neither placeholder nor test starts a service.
