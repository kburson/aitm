# #429 Native headless process usage

## Question and disposition

Explicit headless launch demonstrated process-scoped result and completion usage on three local, authenticated native harnesses. It gives the caller a known assignment before launch and a structured completion surface. The interactive and retrospective probes already obtained usage for correctly scoped local turns. Headless launch therefore improves capture and attribution ergonomics for workers a caller starts. Existing interactive orchestrator work can still use the routes demonstrated in #427–#428.

## Method

On November 24, 2026, the probe used disposable local workspaces on macOS and recorded assignment and attempt before launch. One wrapper per invocation read stdout with a timeout, retained private stdout/stderr and exit status, and exited. Fresh launch, explicit-ID resume, and post-interruption recovery used exact-text, no-tool prompts. The interrupted process gets a longer text-only prompt and SIGINT after a native start or streaming cue. A separate control uses a fresh session, interrupts a bounded 300-line workload, and submits the **identical prompt** as a new execution under the same session ID. All three retries returned all 300 expected lines. The adapter replayed a captured retry receipt without another model call and deduplicated it by its verified observation identity.

Codex and Claude were configured with read-only or tool-restricted options. Grok disabled memory, plan mode, subagents and web tools. Its stream still advertised tools even with an empty tools argument. No tool invocation or delegated work was observed. Provider sessions and raw traces are private. The adapter checked exact retained native evidence only for the two known test sessions per provider.

## Reconciliation and billing boundary

- **Codex:** Preserve the exact thread binding. Difference cumulative counters only with a trusted baseline and verify against the rollout when exact turn identity is required. Cached input is included in the reported input total. Keep a gap for aborted attempts with no numeric observation. Stdout and the tested retained observations did not establish a billed charge or subscription credit delta.
- **Claude:** Keep request-linked `model_usage_since_last_result` and its list-price basis. Across the four primary attempts it totals **$0.0142264** in observed list-price equivalents, including **$0.0008823** of partial interrupted usage. The primary aborted result’s top-level cost included that partial observation. After the next resume, the final top-level result shows **$0.0133441**, which excluded the previous aborted observation on resume. It would lose evidenced work as the sole ledger input. The identical-prompt pair produced independent list-price observations of **$0.0045644** and **$0.0100639**, with the retry summary likewise excluding the aborted attempt. These terminal summaries can drop previously evidenced work on resume. The result and retained log do not verify the subscription bill.
- **Grok:** Keep the native cost ticks and the distinct meanings of input in each surface. For these records, persisted input equals streaming uncached input plus cache-read and cache-creation input. Reasoning tokens were reported within output and were not added to the total. The completed primary attempts total **305,986,400 native USD ticks**, matching the retained session total. Cancelled usage remains unknown. The Grok indicators do not verify a billed charge.
- **Replay versus execution:** Including one replay, primary capture delivered four receipts each for Codex and Grok and five for Claude, leaving three, three, and four unique usage observations respectively. The identical-prompt retry was a separate execution, verified in each session. A replay did not change measured totals. Replay covered the successful retry receipt. Replay of an aborted or partial observation was not exercised. These checks concern accounting deduplication. Provider charges were outside the observable evidence.

The outcomes are one primary path and one bounded same-prompt interruption control per provider and version. All three probes used the existing signed-in account paths. The adapter supplied no separate API key. No alternative API-key route, spend settlement, quota entitlement change, remote surface, or parallel or nested attribution was qualified.
