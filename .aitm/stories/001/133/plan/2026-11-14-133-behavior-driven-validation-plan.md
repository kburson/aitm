## Working model

Each test proves an observable user outcome, a protective boundary, or an invariant with a concrete failure it would catch. Use the cheapest layer that faithfully proves the behavior. Preserve high-fidelity boundary tests, including real process or filesystem checks when those are the behavior under test. Coverage informs review and remains subject to the existing policy. Use behavioral equivalence and regression witnesses to assess consolidation. Treat repeated assertions, incident history, and test expense as evidence for review, with no deletion quota.

Routine stories should get local feedback and a short PR validation path driven by the changed behavior and its dependencies. Include changed tests and mandatory checks, explain the selected IDs, and widen to the complete applicable suite when selection is uncertain. The independent agent review still receives exact candidate evidence. A separately scheduled default-branch full suite catches escaped regressions and interactions off the story path, with no ordinary story waiting for it. A confirmed regression calls for a human-activated trunk-only merge hold. Use one nominated, independently reviewed repair with the normal validation, and a fresh full green on the repaired trunk before manually lifting the hold. Work on other refs continues.
