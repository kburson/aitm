# #120 narrowed Refine for the wake and park scheduler

The independently accepted M10 split leaves #120 at Rank 240. Its development boundary is one private wake ingress, one scheduler, explicit park, and the generic sender and private launcher contract. The successor installer story retains native descriptors, provider configuration, activation and the Grok-specific proposal producer. #121 retains the coordinator process, wake completion and root-watch reconciliation.

## Contract and checkable behaviours

- Use an AF_UNIX stream endpoint in the pinned private monitor root with the portable filesystem-address length checked before binding. Bind the absolute private path while holding the existing verified directory pin, verify the new socket inode through the pinned directory descriptor, then accept traffic. Validate handle and peer with checked ctypes for Darwin getpeereid and Linux SO_PEERCRED. Reject wrong UID before payload parsing. Bound bytes, framing and per-connection work. Reuse existing private path pins and approved-source resolution. No new qualification authority arises from a socket credential.
- Resolve only an allowlisted native locator under the existing registry and adapter. A raw string can only propose the lookup. Verify ingress field allowlists after resolution and persist only service-keyed information, including provider, session and verified turn if available. Keep at most one retained wake hint per admitted key/generation. Use the existing pinned private publication primitive for the durable hint and ephemeral ownership of a due work item. Define the exact serialized keyed hint and native bounds at JIT without adding a routing journal schema.
- Active, Settling and Parked are scheduling states. Schedule a final verified catch-up before park. A newer generation or verified append reopens a parked session. A stale stop cannot park a newer turn. A failed unit of work retains its durable hint and a bounded monotonic retry. Restart discards the process-local lease and uses the retained hint plus native cursor as the recovery input. Accept a separate wake retirement method at JIT. The scheduler never writes the native cursor or assigns work scope. The fake coordinator tests #119 capacity fairness and acknowledgment. Cap work per stream and round so a full destination cannot starve other due sessions.
- The generic sender uses a fixed monotonic deadline with no wait for provider/model output. JIT freezes a measurable send budget and native framing. It returns a best-effort disposition for absent, saturated or refusing ingress. Its stable launcher only resolves owner-approved settings at the existing private monitor root. The park command carries only a current keyed session selector. M10b tests installed provider progress and checks every descriptor contains no checkout, state or socket path.

Also verify wrong UID, unsafe endpoint, invalid length and unknown locator, privacy of durable hints, failed or interrupted scan retaining the exact work, bounded sender and a full project beside an available project.
