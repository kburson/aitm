# #112 design, plan and pickup · November 10, 2026

M02 follows the accepted #100 design and [plan](../../100/plan/multi-project-usage-monitor-implementation-plan.md#m02-atomic-publication-and-restore-operations) at SHA-256 `8899a4d1c35c2e2508d0ae3278f91261795e22bdba9955e96264cb4e414e5f21`. #111 is closed and Done. The reviewed merge `c0371cc2363c1e95892fdcad75aa20181abeba20` is the current delivered trunk and passed [trunk CI](https://github.com/kburson/aitm/actions/runs/42834264238). Full-Auto covers source delivery.

**Design.** Bind descriptor-relative Darwin `renameatx_np` and Linux `renameat2` through checked ctypes in `host_fs.py`. Select independent native flags for exclusive publication and exchange. For no-replace publication, return true on success and false only for EEXIST. Unsupported hosts, absent functions and other failures raise a sanitized host filesystem error. Exchange succeeds atomically or raises without an emulated fallback. Callers retain their existing pinned-path checks, cleanup, domain errors and directory fsync after a successful mutation. Export collision still validates exact replay. Failed restore exchange must leave both original directories in place. Preserve intentional same-directory replacement of pending inbox files and owned plist updates.

**Plan.** Change `host_fs.py`, `scopes.py`, `export.py` and `backup.py`. Service registration, anchor and heartbeat publication and installer retained wheel, runtime and operation record publication already share the scope helper. They pick up the boundary through that existing seam. Keep their caller paths and replay behavior and test them through the existing suites. Retarget both existing export races to inject at `publish_noreplace` and retain their original assertions. Add red tests for file and directory inode preservation on collision, exchange and both restore parent syncs, and missing or refused primitives with original store intact. Run the scoped tests and the full locked package, quality, native CI and both unrounded raw line floors. Check the actual candidate on Darwin and a credential-free, disposable local ext4 volume in the #102-pinned aarch64 image. The JIT probe on that volume swapped two directory inode identities via real `RENAME_EXCHANGE` and synced their parent at UID 65534. This is filesystem evidence. Native providers and systemd are #129 gates.

**Pickup.** Estimate 2.5 implementation agent-hours against the four-hour cap. Use fresh isolated branch `codex/aitm-112-atomic-filesystem` from the pinned trunk above, targeting trunk. Codex implements and owns closure after exact hosted CI, independent source review, verified delivery and the signed retrospective. Production cutover remains a separate decision. Return to Planning if scope or the bounded estimate changes.
