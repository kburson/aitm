## Design

Own `tools/story_dashboard/render.py`, `tools/story_dashboard/dashboard.html` and `tools/story_dashboard/tests/test_render.py`. `render(snapshot: Snapshot) -> str` consumes only the delivered A05 normalized schema. The command `python -m tools.story_dashboard.render --snapshot FILE --output FILE` writes one standalone offline file using A05's physical output protection. Validate the exact A05 schema, repository and lowercase 40-hex planning pin before embedding. The page contains a compact accessible story table and drilldowns, with stable epic, state and Actual coverage filters. Derive epic options from rows with nonempty validated descendants. Selecting an epic includes the epic and its descendants. The primary elapsed column shows all-phase elapsed or all-phase age with an explicit label. Keep implementation elapsed and age in the drilldown. Show state, last progress, estimate scope, Actual, both elapsed/age scopes, Owner wait, Cost, evidence coverage, planning commit/committer time, as-of, and usage selector/cutoff/rate basis. Drilldowns show direct versus descendant Actual, observed working wall time as a separate calendar union, phase/role contributions, measure evidence-through and basis, and approved source links. Display decimal hours and duration from supplied units. Display Unknown and partial for the individual measures, including pending owner wait when flagged. Use inclusive Cost as API-equivalent USD with separate pricing coverage, selector cutoff and evidence-through. Keep all-phase Unknown when only implementation elapsed is known. Never project timings or Cost again in the browser.

Serialize the canonical snapshot into an inert script with escaped less-than signs, including closing-script sequences. Build dynamic text with textContent or DOM methods, with no HTML interpolation for story or evidence strings. Derive story links from the validated AITM repository and positive numeric ID. Parse evidence URLs, allow only HTTPS on the exact GitHub repository, and accept only canonical issue or planning-commit blob paths under the story tree. For a blob, require exact agreement with A05's canonical evidence link for the row's supplied evidence path and snapshot planning pin. Reject credentials, even an explicit default port, queries, fragments other than exact line anchors, duplicate slash, dot segments, percent encodings and noncanonical IDs. A snapshot path cannot also be the output, including by alias. Render the label alone for rejected URLs. External links initiate only on explicit click. Use one static inline stylesheet and script, a restrictive CSP, and no automatic remote loads. The visible page works at desktop and narrow widths with standard local font fallbacks.
