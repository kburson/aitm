## Required changes

- **SPR-181-C-01. Preserve coverage during separate field updates.** Plan lines 58–61 require both a numeric value and its coverage, but only state that an interrupted readback should be tested and unresolved drift held. A transition from an existing Complete number to a partial number can fail after the numeric write, leaving the new value displayed as Complete. The delivered #191 path already sets and reads back Pending verification coverage before writing Actual, then verifies the numeric result before publishing final coverage. Require the M2 writer to prove atomic value-and-coverage replacement or preserve that ordering with an equivalent conservative, read-verified intermediate state. Apply the invariant to Actual, Elapsed and Owner wait. Add a complete-to-partial interruption fixture that checks visible state before recovery as well as final readback. [Delivered #191 checklist](https://github.com/kburson/aitm/blob/9fab8da0de9326b7b307fb627c23f12680674330/.aitm/stories/001/191/story.md#L36)

Its prerequisites and work at lines 43–46 name timing adoption contracts, while C44 and M14 are on C04. C05 Actual requires C02 at line 33. Limit C02 acceptance to timing adoption and preservation of original or opaque usage provenance. Put usage ingestion and reconciliation under C04 and its existing dependencies.
