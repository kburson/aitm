## Refinement decisions

- Release automatic Actual on its own evidence and writer gates. Cost may arrive later. The same qualified report can drive the board and viewer with independent timing and pricing cutoffs. Supported Core timing paths can qualify even when a provider cannot supply native timing or priced usage.
- Keep tool-inclusive Actual separate from the narrower Core implementation-trip clock. Count in-turn tool time once, union repeated evidence for one actor, sum concurrent distinct actors and each descendant once, then add direct epic work. Preserve calendar elapsed, observed working wall time, owner wait and idle as separate measures. Carry verified partial numbers with visible coverage and keep them out of estimate calibration.
- Keep verified priced and unpriced usage separate. A covered zero is admissible only with affirmative evidence for that scope. A missing, disputed or unpriced report leaves new board Cost blank. Reconcile a previously written value under M2 field authority before changing it. Never infer billed spend, price from duration, or assign project-level unattributed tokens to a story.
- Keep data ownership with the existing epics. #181 defines the reporting view and acceptance fixtures. #2 and M3 own activity admission and missing workflow facts. #100 owns capture, qualification, routing, pricing and export. M2 owns the writer and M6 the hosted reader. Record one upstream handoff for each missing contract and reuse it across consumers.
- Slice C is suitable for conditional plan review. Runtime pickup waits on the named, exact prerequisite for each slice. The A/B estimate is 26.0 h. The Slice C estimates in the linked plan cover integration effort and exclude already-owned upstream implementation. [Slice C implementation plan](2026-11-11-181-slice-c-implementation-plan.md)
