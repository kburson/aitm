## Native order and coverage

Match an adapter's keyed checkout to a single currently pinned registered anchor. It qualifies only project attribution when no story is proven. Keep explicit Project-wide work distinct from Unattributed. A valid ordinary verified scope supplies project proof where anchor evidence is absent. If it disagrees with a different verified anchor, hold both totals for the bounded affected span. An unauthorized proposal cannot create an attribution conflict.

A verified handoff names the current project, destination, scope and expected generation immediately before the target native request or turn. A unique anchor initializes generation zero. Verify the current project, capture permission and preserved checkout lineage independently. A→B→C can retain the same verified physical A anchor, but the second handoff names B and proves that unchanged A lineage. A new unrelated checkout or stale before-generation fails closed.

Group independently valid competing handoffs by source, verified stream, the **target native ordinal** and its before-generation. Different receipt ordinals can target the same boundary and conflict. Command-derived boundary or receipt IDs cannot hide the shared target. Reproject the affected suffix whenever an earlier verified transition arrives late. A previously effective later transition whose before-generation becomes stale is held. Exact retries have one effect. Preserve original ranges and return the affected observation keys and scope span to the later journal. M09/M13 own post-ACK and published-snapshot changes.

Persist bounded provenance-only proof holds and immutable first-seen UTC expiry under the coordinator. Cap unresolved entries at 256 and first expiry at 15 minutes. New overflow becomes an explicit gap while existing holds keep their original expiry. Cap the private snapshot at 1 MiB with a sanitized fail-closed disposition. Use a trusted UTC clock injection for deterministic replay. A verified explicit disposition can resolve only its independently matched evidence and range. Release to prior scope only when continuity and absence of another claim prove it. Expiry and overflow release no usage.
