# #39 held at the graduation contract

The scoped JIT readback found a difference between the accepted [C30 acceptance contract](../story.md#accepted-decomposition-excerpt) and the C21/C22 interfaces present at integration base `a49475e75d7e18541f78420e55f7caaa10ae6468` (tree `9e0d32c2946893f6a1177beef91e08a15479391f`). C30 requires the winning child and reciprocal origin/child event facts to publish in one graduation transaction, with normal typed attempt preflight on both local and shared paths.

- C22 invokes the three-argument finalizer after choosing the child. It passes the frozen intent, child number and pinned snapshot. The callback receives neither the fresh candidate operation ID nor the context needed to encode its events. Local numbering and external finalization each generate that ID inside the graduation path. The planning backend requires all event rows to match it. [Registry](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/graduation.py#L103-L133) · [External build](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/graduation.py#L676-L690) · [Backend envelope check](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/store/backend.py#L109-L124).
- C22 builds the new child's event stream before materializing related changes. Its destination overlap check expressly rejects appending the reciprocal child events to that stream in the same graduation operation. [Child append and overlap rejection](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/graduation.py#L390-L409).
- Both commit paths create new service ports carrying only the write authorizer. An attempt-bearing graduation therefore reaches the backend without the required typed preflight, including when the caller has a fixture preflight. [Local and external commit](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/graduation.py#L597-L611) · [Shared staging](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/providers/local.py#L213-L240) · [Normal attempt preflight](https://github.com/kburson/aitm/blob/57beba9316a3ea18f505c87b9ad2b1800b9f4896/packages/aitm-core/src/aitm_core/store/backend.py#L134-L156).

Two temporary probes against real Git used the C22 topology and installed policy fixture. Each created a draft, bound a registered finalizer and tried to build candidate #43. The child-append case was refused with `Related finalization overlaps the base graduation.` The origin-only case built but returned `integrity-error` with `event is outside the operation's story or identity` when an event carrying an independent operation ID reached commit. Both asserted the planning tip remained at the original pin. Result was 2 passed in 19.86 seconds. The probe was run outside the product test collection. The preflight wiring gap is a source finding.
