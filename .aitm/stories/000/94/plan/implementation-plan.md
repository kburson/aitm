## Pickup detail

Reuse U01 authenticated state guard/ACL boundary, U08 registration and service, and U07 fixed-cutoff export proof. Only install.py, backup.py, cli.py and test_install.py. Pin Python 3.13+ to safe absolute interpreter and verify wheel digest, exact metadata and package environment with zero runtime dependency resolution. Store sibling environments by version/digest. Use exact absolute ProgramArguments, project-specific LaunchAgent label, RunAtLoad/KeepAlive, and recover the previous plist/environment on failed launch. Do not activate the production project in this leaf. Make stop/uninstall preserve ledger and key. Verify exact prior runtime and retain rollback material before mutation.

Back up a fixed SQLite snapshot using the SQLite backup API and validated associated private key and project identity. Verify directory ancestry and inherited ACL on backup and restore before accepting private data. Restore a stopped compatible exact target, holding its stable guard, with atomic replacement and fail-closed validation of all bytes before publishing. Prove valid replay and fixed-cutoff parity with stable pseudonyms, actual Mac inherited ACL rejection, no canaries outside key and rollback using two exact wheel environments and fake launchctl. Preserve reviewed same-schema compatibility constraints. Estimate four agent-hours. Stop for cap or ownership change.

Check the actual launchd job identity, loaded program path and fresh compatible service evidence after a bootstrap. The launchctl exit alone does not prove service health. Stop and suppress KeepAlive respawn before acquiring the replacement writer guard, then verify stopped state while proceeding under that guard. Retain the exact previous plist and rollback wheel before upgrade. Cover crash/retry or failed startup without losing the earlier owned path. On backup use the lease-free pinned reader snapshot and capture a matching key from the same verified identity, independently checking the backup copy's sequence and schema. Include no raw registration paths in public backup/restore receipts. Restore the supported store atomically under the stable outer guard. Do not overwrite unrelated host services, install globally, activate production, or remove retained state from this leaf.

For whole-state restore or backup replay, preserve U08 accepted source-anchor proposal and its exact command-ID + sequence private route attestation alongside the ledger, plus accepted registration. The service refuses missing exact authority rather than acknowledging a now-inactive anchor. If restoring a stopped existing root, its current private registration/anchor artifacts may remain outside the atomically replaced state directory only after validating parity against the restored ledger view. Preserve private pending queue and Claude session attestations when retained. See exact U08 final handoff before selecting the recovery protocol.

V1 restore supports the stopped existing registered root. Lease-free SQLite backup produces a fixed sequence and captures its matching key and exact private authority needed by that view: canonical registration, accepted anchor proposals and command-ID plus committed-sequence attestations, ignoring later accepted anchors and treating live queue and Claude session assertions as independent target-side state. Backup manifest binds verified bytes and cutoff, never exposes raw private paths. Validate the backup against that exact view and prove an anchor accepted concurrently is included only if its receipt and matching immutable authority exist at the chosen cutoff. Before mutation, validate the candidate DB/key and its required authority against the target's retained exact private registration/anchor state. Refuse any required proof mismatch before store replacement; do not replace private registration, queue, ACK or session assertion state. A live pending queue can remain only if the exact existing entries can be replayed safely against the restored view; otherwise refuse without mutation. Under the same guard, stage a clean DB/key store with no inherited stale target WAL/SHM, then atomically replace the whole store. Prove fixed-cutoff export/key parity and unchanged target on mismatched proof or interrupted staging.

Serialize lifecycle operations independently of the writer lease using a stable private operation guard. Suppress KeepAlive and confirm job stopped, then take the existing project writer guard for stopped-state mutation and verify the job is still stopped. Release writer guard before bootstrap or rollback bootstrap so the collector can acquire it; retain operation serialization throughout. Preserve the exact previous plist bytes, environment/wheel digest and backup in a recoverable private interrupted-upgrade record before cutover. A fresh successful activation requires the actual loaded job's exact environment executable/digest and a compatible healthy service heartbeat newer than the bootstrap, even for equal version labels. Old same-version heartbeat is insufficient. Exercise interrupted retry, stale health and a failed new launch that restores the exact prior executable and plist, or retains explicit recovery evidence when prior launch also fails.

CLI publishers take the existing inbox publication mutex independently of the writer guard. For restore, hold that mutex under the stopped writer guard from target pending and ACK validation through atomic store swap, using the validated private inbox even when initially empty. Validate any retained final ACK against the exact durable receipt in the candidate restored view; refuse ahead, conflicting or unverified ACKs and unsafe pending commands before replacement. Do not retire or rewrite queue/ACK files to force parity. Test an older backup with a newer retained final ACK, and a racing publication fenced until after swap.
