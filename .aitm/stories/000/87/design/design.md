A delayed scan that sees a marker must still start eligible usage exactly after the proven boundary; no observation or private raw input from earlier unbound work reaches the ledger. Advance sanitized source/counter checkpoint only according to the accepted rules and use explicit Unknown coverage for in-flight cutoff, loss of continuity, malformed/unsupported usage and known turn activity with no usage evidence. No provider billing or pricing logic in U03. Keep raw path, cwd, transcript contents and raw provider IDs transient. Validation failure diagnostics use closed labels and keyed refs only.
