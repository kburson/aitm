U02 turns typed private commands into append-only enrollment, scope and correction records. Its commit unit is the effect plus its current disposition. The input queue uses atomic publication and exact closed shapes. Commands carry project-authenticated references, a typed ID and stable bytes for replay. Pending evidence can advance to one final disposition. Replays return the current recorded outcome and conflicting bytes preserve prior state. Ignore uncommitted temporary publications. Later leaves add their own dispatch cases and U12 exercises the separate-process crash gap.

Ordering uses approved-source evidence with matching provider and session, and an explicitly proven preceding serialized receipt or next-turn boundary. File-arrival order is independent of provider order. Codex Desktop uses the invoking CODEX_THREAD_ID only transiently, checks it against the provider source and retains the pseudonym. Claude Code uses the reserved session UUID or the verified native join identity. Use the shared boundary fixture seam, leaving real parsing to U04 and U05 and continuous delivery to U08. A timestamp alone never validates a boundary. A pending or contradictory claim leaves affected usage Unknown. The effective segment can be enrolled without importing previous unbound usage.

A verified development binding carries owner, anchor, provider session, attempt and generation. Compatible marked reviewers retain their own role; a same-worktree stranger remains Unknown. Hash raw enrollment inputs on the authorized local route before any durable write. Publish through private checked inbox paths without taking the ledger writer guard. Only the consuming writer takes the guard and commits the effect and disposition.
